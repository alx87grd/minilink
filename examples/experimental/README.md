# Experimental demos

Tracked single-file demos that are **not** canonical teaching entries:

- Non-core features (e.g. physics engine, symbolic mechanics)
- Scenario / mission matrices beyond one flagship per feature
- Versioned WIP (`*_v2*`)

Canonical feature demos stay under [`../scripts/`](../scripts/). Multi-file
named experiments belong in [`../projects/`](../projects/).

Personal quick checks: [`scratch/`](scratch/).

Not listed in the root README examples table; not part of the intro-doc surface.
Not run by default CI flagship checks unless explicitly added later.

Run from the repo root, e.g.
`PYTHONPATH=. python examples/experimental/engine/demo_physics_in_diagram.py`.
