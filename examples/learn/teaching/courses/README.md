# Courses

Syllabus-tied teaching packs (labs, problems, lecture snippets).

Layout per course::

```
courses/<course_id>/
  README.md
  labs/          # .ipynb
  problems/      # student starter .py
  lectures/      # optional in-class demos
```

Public repo: no graded solutions (keep those private).

Not smoked by CI — add material when porting from pyro `examples/courses/`.
